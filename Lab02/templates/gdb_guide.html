PHÂN TÍCH LOCAL

Hướng dẫn GDB an toàn

Dừng tại process_name, quan sát biến local, stack frame, signal và backtrace. Không thay đổi thanh ghi hoặc return address.

Chỉ chạy trong WSL, Linux VM hoặc Docker local

GDB cần SYS_PTRACE trong profile Docker riêng. Web service thông thường không dùng quyền này và container không chạy privileged.

Input bình thường

gdb -q build/vulnerable_debug
break process_name
run "Le Minh"
frame
info locals
p sizeof(name)
backtrace

Mục tiêu: xác định hàm, kích thước buffer và kết quả exit bình thường.

Input A lặp 64 lần

gdb -q build/vulnerable_debug
source gdb/inspect_overflow.gdb
run "AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA"
backtrace
frame
info locals
info registers

Mục tiêu: quan sát signal, vị trí dừng và backtrace. Không điều khiển luồng thực thi.

Script có sẵn

gdb/inspect_normal.gdb gdb/inspect_overflow.gdb gdb/inspect_hardened.gdb gdb/README_GDB.md

Địa chỉ bộ nhớ chỉ quan sát thủ công trong GDB local, không hiển thị trong giao diện web chính.
