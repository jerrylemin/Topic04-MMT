## Bảng kiểm nhiệm vụ, phòng chống và nộp bài

- Lab01: thực hiện Reflected, Stored và DOM-based trên route local; đối chiếu source–storage–sink; đề xuất output encoding, `textContent`, sanitization, CSP, HttpOnly/Secure/SameSite và validation.
- Lab02: gửi input thường/dài, quan sát response hoặc crash thật, dùng GDB/ASan khi người học tự chạy; vá bằng kiểm tra 31 byte và `snprintf`; trình bày Canary, PIE, RELRO, ASLR, NX, request limit và memory-safe language.
- Lab03: sửa `price`, `invoice id`, `role`; đối chiếu server price, owner-or-admin và field allowlist; ghi audit hành vi bất thường.
- Lab04: ghi request hợp lệ, mã form attacker local, trạng thái trước/sau, rồi chứng minh secure route từ chối; triển khai token theo session, Origin/Referer, SameSite, POST-only và re-auth.
- Lab05: thử input bình thường, dấu nháy, authentication bypass và search mở rộng bằng chuỗi cố định trong repo; không dùng payload phá dữ liệu; vá bằng parameter binding, PBKDF2, generic error, least privilege, logging/monitoring.
- Lab06: quan sát cookie/flags, sửa Plain và Base64 bằng DevTools thủ công, kiểm tra Signed/Encrypted/Server session; không lộ token dài; server lấy role từ database và hủy session khi logout.
- Bài nộp chung: mục tiêu, môi trường, bước thực hiện, kết quả, nguyên nhân, ảnh hưởng, phòng chống, bản vá, bài học và phụ lục ảnh/log/request-response. Deck chỉ tạo placeholder; người học tự chụp ảnh thật theo `HUONG_DAN_CHEN_ANH_PPTX.md`.
