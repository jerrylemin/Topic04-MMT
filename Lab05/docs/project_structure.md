# Project structure

- Cac module Python goc: Flask route, SQLite, auth, validation, query, trace,
  audit, error va security helpers.
- `templates/`, `static/`: UI server-rendered, inspectors, timeline, visualizer
  va Presentation Mode.
- `scripts/`: reset, fixed demo flows, evidence, smoke, report, screenshot check
  va cleanup.
- `tests/`: behavior, security boundary, evidence va report acceptance tests.
- `evidence/`: artifact da che thong tin nhay cam tu cac flow chay that.
- `report/`: DOCX/PDF cuoi cung sinh tu source va evidence.
